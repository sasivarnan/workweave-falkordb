Title: FirstTask — catch outdated advice before a new employee acts

FirstTask helps a new engineer make a first contribution using current company guidance. FalkorDB connects employees, tasks, services, approved decisions, original documents, training and reviewers. It finds the starter guide that contradicts a replacement decision, preserves the evidence behind a saved plan, and flags the plan when the decision changes. A stored review request is allowed only after the current prerequisites are met.

The demo includes an employee home, a live graph walkthrough, query evidence and a reproducible eight-case diagnostic. OpenAI reads graph context and selects a small supported A2UI layout. The UI uses official shadcn components.
