# FirstTask demo script

Target duration: about two minutes. Record only after the hosted URL and live model are verified.

1. “A new employee needs to make a checkout change. The starter guide is outdated.”
2. Show the assignment and ask the live agent what must happen first.
3. “FalkorDB connects the assignment, service, old guide, and approved replacement decision.” Open the evidence path and source.
4. “The agent selects a workspace from a small A2UI catalog. Facts come from the graph.” Show the comparison and learning plan.
5. Select Replace Decision. “A judge can change the sample graph. The plan now uses the new decision.”
6. Accept the plan. Complete training.
7. Start a new session. “Progress is retrieved from FalkorDB without the old conversation.”
8. Remove the owner. “The portal reports missing ownership instead of inventing a reviewer.”
9. Open the execution view. Show the actual query, arguments, result count, and duration.
10. “FirstTask helps a new employee act on current guidance. The public sample uses fictional company data.”

The automatic walkthrough runs real graph actions without a model call. Label it as graph-tool exploration. Use Ask Agent separately to demonstrate the live model.
